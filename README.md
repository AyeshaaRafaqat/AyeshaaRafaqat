### 🏗️ Production Systems

#### 🔮 [Pyxis](https://github.com/AyeshaaRafaqat/pyxis) — AI-Driven Technical Interview Platform
*An intelligent, multi-database technical evaluation service leveraging semantic search.*
* **Architecture:** Combines **PostgreSQL (pgvector)** for high-dimensional embeddings, **MongoDB** for flexible session logs, and **Neo4j** for graph relationships.
* **Key Mechanisms:** Multi-phase evaluation session tracking, rolling-summary contextual memory, private candidate per-answer scoring modules, and semantic portfolio analyses.

#### ✈️ [LearnPilot](https://github.com/AyeshaaRafaqat/learnpilot) — Modular Roadmap Generator
*A personalized learning-path generator built using strict OOP guidelines and decoupled services.*
* **Architecture:** Enforces clear separation of concerns across 3 independent service layers: **Authentication**, **Content Generation**, and **Analytics**.
* **Key Mechanisms:** Robust domain logic mapped over 6+ highly performant REST endpoints.

### 📈 Engineering Focus & Optimization

* **System Automation & Pre-rendering:** Architected custom pre-deployment scripts that dynamically pull live API data to auto-regenerate **80+ pre-render routes**, completely eliminating manual routing updates and maximizing search performance.
* **Dynamic High-Performance Routing:** Implemented intelligent request-time routing endpoints to dynamically load multi-type records (courses, blogs, profiles) with minimal query overhead.
* **Complex Data Modeling:** Designed robust schema structures, vector-indexed query engines, and graph entity relationships optimized for heavy read/write concurrency.
